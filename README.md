# 하다말 아카이브

로컬 미리보기:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

http://127.0.0.1:8000/ 에서 확인합니다.

- `index.html`: 아카이브 홈
- `site-assets/`: 홈 썸네일
- `donki-game/`: 돈키털기 쇼핑 게임
- `weed-license/`: 제초 자격증 시험
- `hit-momonga/`: 모몽가 혼내주기
- `bujeok-studio/`: 부적소 — 부적 만들기와 공유

GitHub main 브랜치에 push하면 Pages에 배포됩니다. 로컬 수정만으로는 배포되지 않습니다.
